# Dataset Information

- **Dataset**: Breast Cancer Wisconsin (Diagnostic)
- **Authors**: W. Wolberg, O. Mangasarian, N. Street (University of Wisconsin)
- **Source**: UCI Machine Learning Repository, license CC BY 4.0
- **Copy used**: Kaggle re-upload "Breast Cancer Dataset [Wisconsin Diagnostic UCI]" by abhinavmangalore
- **Note**: The `id` column is dropped and diagnosis is encoded as 1 = malignant, 0 = benign.
